# 🧠 我的资料库大脑（Second Brain）

这是我的个人知识库：收集、整理对我有用的资料，让各种 AI 读完后成为"懂我资料"的助手。

## 📁 目录结构

- `articles/` —— 收藏的好文章、教程
- `notes/` —— 学习笔记、心得
- `howto/` —— 操作手册、踩坑记录
- `ideas/` —— 想法、灵感

> 资料放得越有结构，AI 读起来越聪明。建议每篇文档开头先写一句"这是什么"。

## 🤖 如何在各种 AI 中使用

| AI | 用法 |
|----|------|
| ChatGPT / Claude | 新建一个 Project/项目，把本仓库的文档上传进去 |
| Kimi / 豆包 | 直接粘贴本仓库链接，或下载 ZIP 后上传里面的文档 |
| NotebookLM | 把下载的 PDF / Markdown 文件添加为资料源 |
| GitHub Copilot | 在 VS Code 中克隆本仓库，Copilot 自动理解全部资料 |

## ➕ 如何添加资料

1. **网页（最简单）**：进入仓库 → Add file → Upload files → 拖入文档 → Commit changes
2. **电脑端（进阶）**：装好 git 后 `git clone` → 本地整理 → `git push`

## ⚠️ 隐私提醒

本仓库是 Public（公开），任何人和 AI 都能看到。**敏感、私密资料不要放这里**；如需隐藏，进入 Settings → General → Danger Zone → Change visibility 改为 Private。
